# SmartAlarm Test

Kotlin, Jetpack Compose ve Material 3 ile geliştirilmiş görev tabanlı modern alarm prototipi.

## Derleme

Java 17 ve Gradle 8.11.1 ile:

```bash
gradle assembleDebug
```

Ayrıntılı uygulama durumu ve cihaz testi notları için [PROJECT_STATUS.md](PROJECT_STATUS.md) dosyasına bakın.
